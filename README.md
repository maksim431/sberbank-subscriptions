# Сбер: концепт экрана «Регулярные списания»

Инициативный концепт для СберБанк Онлайн: все подписки, платные услуги Сбера, привязки к сервисам и автоплатежи в одном экране Кошелька. Сумма в месяц, календарь списаний, напоминание до конца пробного периода, подсказка о дублях (платные уведомления при активном СберПрайм) и отключение в один тап с возможностью вернуть.

**Живой прототип:** https://maksim431.github.io/sberbank-subscriptions/

## Почему
Сейчас управление платными услугами разнесено по разным разделам приложения (Сбер ID, настройки карты, «Куда привязана карта», автоплатежи). Человек не видит общей суммы и даты ближайшего списания и узнаёт о нём постфактум. Вывод сделан по открытым источникам: публикации СМИ, разборы на финансовых порталах, истории пользователей.

## Как измерить
A/B-тест: обращения в поддержку по теме списаний, число оспариваний, удержание СберПрайм после пробного периода, CSAT экрана.
